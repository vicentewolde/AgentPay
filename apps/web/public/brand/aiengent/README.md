# AienGent brand assets

The primary identity is a geometric `AI` monogram paired with the `AienGent`
wordmark. The electric-blue terminal represents the point where an agent's
intent becomes an authorized payment action.

## Colors

- Carbon: `#171A1F`
- Electric blue: `#176BFF`
- Off-white: `#F5F7FA`

## Files

- `aiengent-icon.svg`: primary icon for light backgrounds.
- `aiengent-icon-on-dark.svg`: reversed icon for dark backgrounds.
- `aiengent-horizontal.svg`: primary horizontal lockup.
- `aiengent-horizontal-on-dark.svg`: reversed horizontal lockup.
- `aiengent-icon-32.png`: favicon-sized raster export.
- `aiengent-icon-192.png`: compact app/PWA export.
- `aiengent-icon-512.png`: large app icon export.
- `aiengent-horizontal-1280.png`: horizontal raster export.

Keep the blue accent exclusively on the upper terminal. Do not add gradients,
shadows, outlines, or effects. Preserve the SVG view box when resizing.

The horizontal SVG uses a contemporary system sans-serif stack. For a final
trademark master, convert the approved wordmark to outlines in the selected
licensed typeface.
