# AgentPey brand assets

The primary identity is an interlocked geometric `AP` monogram paired with the
`AgentPey` wordmark, pronounced “Agent Pay”. The electric-blue terminal marks
the instant an agent's intent becomes an authorized payment action.

## Colors

- Carbon: `#171A1F`
- Electric blue: `#176BFF`
- Off-white: `#F5F7FA`

## Files

- `agentpey-icon.svg`: primary icon for light backgrounds.
- `agentpey-icon-on-dark.svg`: reversed icon for dark backgrounds.
- `agentpey-horizontal.svg`: primary horizontal lockup.
- `agentpey-horizontal-on-dark.svg`: reversed horizontal lockup.
- `agentpey-icon-32.png`: favicon-sized raster export.
- `agentpey-icon-192.png`: compact app/PWA export.
- `agentpey-icon-512.png`: large app icon export.
- `agentpey-horizontal-1280.png`: horizontal raster export.

Keep the blue accent exclusively on the P terminal. Do not add gradients,
shadows, outlines, or effects. Preserve the SVG view box when resizing.

The horizontal SVG uses a contemporary system sans-serif stack. For a final
trademark master, convert the approved wordmark to outlines in the selected
licensed typeface.
