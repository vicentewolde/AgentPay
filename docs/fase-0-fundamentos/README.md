# Fase 0 — Fundamentos

Documentos producidos **antes de escribir la primera línea de código**: el
análisis de contexto, los planes, y los prompts que dieron origen a la Fase 1.
No son artefactos técnicos; son el rastro de las decisiones estratégicas que
llevaron al código.

| Archivo | Qué es |
|---|---|
| `pagos-agenticos-ley-fintech-chile.md` | Referencia sobre protocolos globales de pagos agénticos y la Ley Fintech 21.521 |
| `prompt-mvp-chile-latam.md` | Primer prompt exploratorio: MVP para Chile/LatAm |
| `plan-agentic-payments-stellar-scf.md` | Roadmap original de 10 semanas hacia la postulación a SCF |
| `prompt-claude-code-kickoff.md` | Prompt de arranque para Claude Code |
| `prompt-chat-consulta-tecnica.md` | Prompt para el chat de consulta técnica |
| `AgentPass-plan-tecnico-fase-0-1.md` | Plan técnico ejecutable de las semanas 2–3 (el brief que originó T1–T8) |
| `claude-code-mensaje-inicial.md` | Mensaje inicial con el que arrancó la construcción de AgentPass |

Estaban sueltos en la raíz, en carpetas llamadas `Informacion/`, `prompt 1/`,
`Prompt 2/` y `Prompt 3/`. Se aplanaron aquí porque esos nombres eran del
flujo de trabajo local, no estructura con significado — y los nombres de
archivo ya dicen de qué se trata cada uno.
