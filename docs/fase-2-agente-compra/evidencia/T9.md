## Mutation testing

Cuatro protecciones rotas a propósito, para comprobar que los tests las cubren
de verdad y no por coincidencia.

| # | Mutación | Resultado |
|---|---|---|
| M1 | `parseVenueId` hace `trim()` del input | **1 test cae**, y es el correcto: `is not lenient: whitespace is part of the identity` |
| M2 | `parseVenueId` normaliza (`trim` + `toLowerCase`) | **7 tests caen** en `ids.test.ts`, y `catalog.test.ts` / `mock.test.ts` ni siquiera cargan: `MOCK_VENUE_ID` deja de construirse |
| M3 | `parseProduct` no valida, devuelve la fila cruda | **14 de 19** tests de `catalog.test.ts` caen, más 1 de `mock.test.ts` |
| M4 | `getProduct` devuelve `undefined` en vez de lanzar | **2 tests caen**: `throws ProductNotFound…` y `matches ids exactly…` |

### El hallazgo de M1

En la primera pasada, M1 **no rompía nada**. El test que debía cazarla decía:

```ts
expect(() => parseVenueId(` ${canonical}`)).toThrow();
```

y con la mutación seguía en verde — porque `trim()` + `toLowerCase()` deja el
contract id en minúsculas, StrKey lo rechaza, y la función lanza igual. El test
pasaba, pero por una causa distinta a la que pretendía probar. Cubría la
mutación por accidente, no por diseño.

Se reescribió para exigir la **razón** exacta del rechazo:

```ts
try {
  parseVenueId(` ${canonical}`);
  expect.unreachable("a padded venue id must not parse");
} catch (error) {
  expect(hasErrorCode(error, "InvalidVenueId")).toBe(true);
  expect((error as { details: { reason: string } }).details.reason).toBe("malformed-slug");
}
```

`malformed-slug` solo puede ser la razón si nada recortó el espacio antes. Con
eso, M1 pasó de invisible a caer sola:

```
 ❯ src/catalog/ids.test.ts (32 tests | 1 failed) 12ms
 FAIL  src/catalog/ids.test.ts > parseVenueId > is not lenient: whitespace is part of the identity, not noise to strip
 ❯ src/catalog/ids.test.ts:67:55
 Test Files  1 failed | 2 passed (3)
      Tests  1 failed | 66 passed (67)
```

Se agregó además una invariante directa, en ambos parsers: lo que entra es
byte a byte lo que sale.

```ts
it("returns the exact string it was given, never a normalised one", () => {
  for (const id of [`bazaar:${CONTRACT}`, `mock-bazaar:${CONTRACT}`, `b2:${CONTRACT}`]) {
    expect(parseVenueId(id).venueId).toBe(id);
  }
});
```

Todas las mutaciones fueron revertidas; la suite quedó en 67/67 verde.
