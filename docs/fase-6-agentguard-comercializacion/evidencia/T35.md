## Verificación en vivo — simulación de una wallet real de punta a punta contra testnet

Un script (`simulate-wallet-t35.mjs`, descartado tras la corrida — no forma
parte del repo) reproduce exactamente lo que haría Freighter, sin ningún
atajo del servidor: `Keypair.random()` + Friendbot para fondear, firma
SEP-0053 real (`signStellarMessage`, la misma primitiva que usa
`@agentpay/core`) para el challenge de wallet-connect y para el
mensaje-resumen del Mandato, y `TransactionBuilder.fromXDR(...).sign(...)`
para firmar la transacción de anclaje/revocación que el servidor devuelve
sin firmar — el mismo mecanismo que usa Freighter internamente para
`signTransaction`.

```

== funding via friendbot ==
friendbot status: 200

== T34: wallet connect ==
verify: { ok: true, address: 'GAWXWUAVZT2WFF7F7VKNY43JKBHIMOESHDILKTKVBIBZJHXMHG2VTFYB' }
```

### 5. El reporte del vault confirma que el Mandato quedó anclado con la wallet como `issuer`, no la plataforma

```
== vault report ==
vault.chain: { ok: true }
vault.identity: [
  {
    kind: 'credential',
    hash: 'c6ec2c53a6a06b05fdb8c95cbaeae4c408ee4f98c561cef09029f37ea4cf5ac0',
    issuer: 'GCTTRJIYYRHAOYTEG2YWKYSBKIQOMX7RX7SAJXQAM3QY2J7J453BOZD6',
    subject: 'GAK6E5E7L63ZYFZZZFXDTYVG6MVAKILSHI5FITGH5U4ORACEZQ4GFP2K',
    revoked: false
  },
  {
    kind: 'mandate',
    hash: 'fb1d17d0828559d284971459e40243703f310a3a0f302292bd778eaec48f99e2',
    issuer: 'GAWXWUAVZT2WFF7F7VKNY43JKBHIMOESHDILKTKVBIBZJHXMHG2VTFYB',
    subject: 'GAK6E5E7L63ZYFZZZFXDTYVG6MVAKILSHI5FITGH5U4ORACEZQ4GFP2K',
    revoked: false
  }
]
```

Nótese: `identity[0].issuer` es la cuenta de la plataforma (la credencial
la sigue emitiendo `ISSUER_SECRET_KEY`, sin cambios); `identity[1].issuer`
es la wallet conectada — es el Mandato, no la credencial, el que cambió de
firmante en este hito.

### 7. Firmar la revocación como lo haría Freighter → confirmar en testnet

```
== sign the revoke transaction XDR ==
revoked: {
  ok: true,
  mandateHash: 'fb1d17d0828559d284971459e40243703f310a3a0f302292bd778eaec48f99e2',
  revokeTx: '84d43395eccd8664b602eeddc5834ad8b363ffe5d70a1dd485de710a571b47e1',
  credentialStatus: 'Active'
}

✅ full T35 wallet flow (connect, anchor with wallet signature, revoke with wallet signature) succeeded end to end.
```

`credentialStatus: 'Active'` confirma lo mismo que ya probaba T21: revocar
el Mandato no toca la credencial de identidad — son dos autoridades
distintas, y siguen siéndolo también en el camino de wallet.
