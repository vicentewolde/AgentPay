Tres cosas quedan probadas contra tráfico real, no contra un fixture:

1. **La fila de prueba de Periplo desapareció sola.** Tres filas entraron,
   dos salieron: la de `accepts: []` no ofrece nada en `stellar:testnet`
   bajo `exact`, así que no es candidata. Ningún caso especial.
2. **Las dos filas legítimas de Periplo salen `unregistered → not payable`.**
   Son servicios x402 reales, que cotizan el mismo SAC de USDC testnet que
   este proyecto usa, y aun así AgentPey no les pagaría: `venues.json` no
   los conoce. Eso es `C-77` funcionando, visible.
3. **El fallback funciona.** Con Periplo apuntado a un host inexistente, el
   índice propio contesta las cinco filas del bazaar registrado.

## 3. La ruta pública, contra el servidor real

Servidor levantado en el puerto 8899 (el 8787 estaba ocupado por otra
instancia del usuario), sin Postgres involucrado — la ruta no lo toca.

```
$ curl -s "http://localhost:8899/discovery/search?query=brief"
{
    "ok": true,
    "source": "agentpey",
    "query": "brief",
    "results": [
        {
            "venue": "stellar-bazaar:CBDWMXZEE44NJ3RA6RS7K4EK36KDFW5S7KHP276HCMM4I52MIUUHEF5B",
            "registered": true,
            "product_id": "stellar-ledger-brief",
            "resource_url": "https://stellar-bazaar-x402.vercel.app",

```

Sin `query`, devuelve las cinco:

```
$ curl -s "http://localhost:8899/discovery/search"
* 5 results
['swap-risk-quote', 'stellar-ledger-brief', 'contract-safety-mcp', 'market-window-mcp', 'sentinel-agent-intelligence']
```

Consulta con un carácter de control, rechazada antes de buscar:

```
$ curl --get --data-urlencode $'query=a\x07b' "http://localhost:8899/discovery/search"
{"ok":false,"code":"InvalidArguments","message":"a catalogue query may not contain control characters","details":{}}
HTTP 400
```

Y la ruta se reclama **antes** del fallback a archivos estáticos sin
romperlo — `/discovery/nope` sigue siendo `404`:

```
$ curl -o /dev/null -w "HTTP %{http_code}\n" "http://localhost:8899/discovery/nope"
HTTP 404
```

Ningún precio aparece en ninguna respuesta, aunque el bazaar cotiza cada
producto: hay prueba dedicada que lo verifica sobre el JSON serializado.
