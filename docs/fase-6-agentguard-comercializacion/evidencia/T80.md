## 2. El recorrido completo, en el navegador

Servidor levantado con `pnpm run realops` y recorrido de punta a punta.

**Portada** — el aviso de piloto (testnet, sin dinero real, datos borrables)
está en el layout, así que no se puede renderizar una página sin él. Enlaza a
SignalDesk para que cualquiera compruebe que los dos servicios existen por
separado.

**Entrar → enlace** — sin proveedor de correo configurado, la página muestra el
enlace y dice lo que eso cuesta, textual:

> Modo piloto sin correo configurado. Todavía no hay proveedor de email, así
> que el enlace se muestra acá. Esto significa que *no se está verificando* que
> el correo sea tuyo — cuando el envío esté configurado, sí se verifica.

## 3. Las garantías, como pruebas

De las 51 pruebas del paquete, las que sostienen el diseño:

```
externalRefFor
  ✓ is random, so the same email never produces the same reference twice
  ✓ contains nothing that could be an email, a RUT or a phone number
magic links
  ✓ stores a hash, never the token itself
  ✓ keeps its three refusals distinct, because they mean different things
  ✓ can only be redeemed once, even by two callers at the same time
what needs a session
  ✓ sends a visitor with no session to the sign-in page
  ✓ does not accept an invented session cookie
agents
  ✓ configures one and shows the literal grant on the review screen
  ✓ answers 404 for another account's agent, never 403
the enforcement labels
  ✓ labels the two limits as on-chain, because the contract revalidates them
  ✓ is honest that the agent's name is only RealOps' business
interpretInstruction
  ✓ refuses rather than guessing when it recognises nothing
  ✓ refuses rather than choosing when the sentence asks for both
  ✓ refuses a pair it does not know instead of substituting the one it does
  ✓ is not steered by text that tries to give it orders
deleting an account
  ✓ erases the email, drops the sessions, and says what it does not erase
```

La prueba de un solo uso corre las dos redenciones **en paralelo**
(`Promise.all`) y exige que exactamente una gane — no que la segunda falle
después de la primera, que es una prueba más débil y pasa aunque haya ventana.

## 4. Un defecto encontrado por un test

El vocabulario de interpretación matcheaba palabras exactas, así que
`"compra dos informes XLM/USDC"` —plural perfectamente normal— no se reconocía:

```
FAIL  src/instruction.test.ts > reads a small quantity, in digits or in words
AgentPassError: no reconoci ningun producto en la instruccion
```

Arreglado matcheando raíces por prefijo, con las palabras de dos letras (`ia`,
`ai`) en coincidencia exacta: una regla de prefijo sobre esas reclamaría media
lengua, y un vocabulario que matchea de más deja de rechazar.

Un segundo arreglo menor, también de la corrida: los botones de respaldo decían
"creditos" sin tilde mientras el resto de la UI usa castellano acentuado.
