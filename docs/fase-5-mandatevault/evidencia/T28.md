```js
const agentpass = await createAgentPass({
  network: "testnet",
  networkPassphrase: "Test SDF Network ; September 2015",
  rpcUrl: "https://soroban-testnet.stellar.org",
  contractId: <AGENT_REGISTRY_CONTRACT_ID>,
});
await agentpass.status("ab4dfb10bb9d07b356ae9a1d4e4eabef8e8c608a8ec780b3f89cc2bfc394827b");
```

anunció — está efectivamente anclado en `agent_registry`, consultable por

en el servidor que lo generó.
